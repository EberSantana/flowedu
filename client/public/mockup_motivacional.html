⚙️ Dados reais que alimentam as mensagens
Dado Fonte no sistema Usado para
Hora do dia new Date().getHours() Bom dia / Boa tarde / Boa noite
Aulas de hoje trpc.dashboard.getTodayClasses "Você tem 2 aulas hoje"
Exercícios pendentes trpc.exercises.getPendingCount "3 exercícios aguardando correção"
Dúvidas não respondidas trpc.studentDoubts.getPendingDoubtsCount "5 dúvidas sem resposta"
Progresso nas trilhas (aluno) trpc.student.getEnrolledSubjects + tópicos concluídos "65% das trilhas concluídas"
Avisos não lidos (aluno) trpc.announcements.getUnreadCount "1 aviso novo do professor"
Respostas de dúvidas (aluno) trpc.studentDoubts.getUnseenAnswersCount "Professor respondeu 2 dúvidas"
Frase motivacional Array fixo de 20+ frases (rotação diária por data) Citação no rodapé do banner
🧠 Lógica de prioridade da mensagem
Prioridade Condição Mensagem gerada
🔴 Alta Dúvidas pendentes > 5 ou exercícios > 5 "Atenção: muitas pendências aguardam você"
🟡 Média Tem aulas hoje + exercícios pendentes "Você tem X aulas hoje e Y correções pendentes"
🔵 Normal Tem aulas hoje, sem pendências "Você tem X aulas hoje. Boa aula!"
🟢 Tranquilo Sem aulas e sem pendências "Nenhuma pendência hoje. Aproveite para planejar!"
📌 Como seria implementado no código
  • Criar um hook useMotivationalGreeting() que recebe os dados já carregados no Dashboard
  • O hook retorna: { greeting, message, chips, frase } baseado nos dados reais
  • Substituir o banner estático atual pelo componente dinâmico
  • Sem nova chamada ao banco — usa dados que o Dashboard já busca hoje
  • Frase do dia: array de 30 frases, selecionada pelo dayOfYear % 30
  • Tempo de implementação estimado: ~2 horas
